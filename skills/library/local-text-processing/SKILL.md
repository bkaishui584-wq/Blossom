# Local Text Processing

## 说明

用户把正文贴进来，我按规则整理一遍再给回去：清掉行尾空白和连续空行、
去掉重复的有内容行、或者数一数字符行数。只处理用户给的那段文字，
不去读别的文件，也不联网、不需要模型。做法是确定的，同样的输入永远同样的输出。

## 触发条件

- 整理文本
- 清洗文本
- 去掉重复行
- 文本去重
- 统计字数
- 数一下多少字

## 输入

- text：要整理的正文
- what：clean 清理、dedupe 去重、stats 统计，不给就按 clean

## 步骤

1. 按规则整理正文 | tool=text_process

## 允许工具

- text_process

## 输出格式

清理和去重直接给整理后的正文；统计给一行数字。改动过的地方说明改了什么。

## 验收标准

- 结果来自 text_process 的真实返回，不自己改写用户原文
- 没有正文时明确说缺什么，不瞎编一段
- 处理规则可复算，同样输入同样输出

## 失败处理

- 没给正文：说明要先把文本放进来，不猜用户想整理什么
- 整理方式不认识：说清只认哪几种，不悄悄换成别的做法
