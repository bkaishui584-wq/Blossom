# Screen & Context

## 说明

只读眼前的上下文，帮 DeskPet 知道用户正在用什么软件。屏幕感知默认关着，
用户自己打开之后才读。只读前台窗口和公开的界面语义，不截图、不录键盘、
不做身份推断，也不把内容发到任何地方。读不到就说读不到。

## 触发条件

- 我在用什么
- 当前窗口
- 前台是什么
- 现在在用什么软件
- 屏幕
- 看看我在干嘛
- 界面上的文字

## 输入

- what：window / semantics / all（可选，缺了按说的话猜）

## 步骤

1. 读当前前台窗口 | tool=screen_context

## 允许工具

- screen_context

## 输出格式

一句读数：应用、标题，以及打开屏幕感知后才能看到的界面文字。

## 验收标准

- 屏幕感知关着时明确说关着，不假装看见了
- 读到的标题和进程名都来自系统接口，不自己编
- 不截图、不联网、不保存屏幕内容

## 失败处理

- 关着：告诉用户怎么打开，不偷偷读
- 读不到：说明这台机器上读不到，不估一个答案
