# Study Agent

## 说明

默认提示优先。先给一层提示，再给推导，最后才是完整答案。
内容要靠模型或用户提供的材料，程序不凭空编造知识。

## 触发条件

- 讲解
- 推导
- 提示
- 错题
- 复习
- 学一下
- 怎么理解

## 输入

- topic：主题
- mode：hint / step / full
- mistake：要记下来的错题（可选）

## 步骤

1. 生成分层讲解结构
2. 记录错题到记忆

## 允许工具

## 输出格式

先提示，再步骤，最后按模式决定要不要给完整答案。

## 验收标准

- 没有材料或模型时不编造结论，只给方法与结构
- 错题记录可被用户查看和删除

## 失败处理

- 记不进记忆：说明记忆不可用，内容照常给出
