# Local Diagnostics

## 说明

用户问「哪里不对」「检查一下」时，把本机真实状态读一遍再回答：
程序目录、数据目录、日志目录在不在、能不能写，数据库能不能打开、多少张表，
陪伴模型和任务模型配了没有，现在有几条持久授权，最近日志里有没有报错行。
全部是读本机，不联网、不要模型。读不到就说读不到。

## 触发条件

- 自检
- 体检
- 诊断
- 检查一下
- 有什么问题
- 错误日志
- 桌宠是不是出问题了

## 输入

- 无

## 步骤

1. 读本机状态和最近日志 | tool=run_diagnostics
2. 读机器状态 | tool=system_status

## 允许工具

- run_diagnostics
- system_status

## 输出格式

按目录、数据库、模型、权限、日志的顺序给几行，每行写清读到的是什么。机器状态单独一行。

## 验收标准

- 每一条都是本机读到的真实值，不美化也不吓人
- 没有配置模型时说明本地功能照常可用
- 读不到的项目明确说读不到

## 失败处理

- 数据库打不开：如实说打不开和原因，不假装正常
- 日志读不到：说明日志没读到，其它项照常给
