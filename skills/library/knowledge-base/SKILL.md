# Knowledge Base

## 说明

用户把自己电脑上的一个目录加进知识库并扫描后，我可以在里面按关键词找片段。
搜出来的是原文件里的一小段，带文件名和第几段，能顺着回去看原文。

全是本地操作：不联网、不上传、不需要模型。索引只覆盖用户明确加进来的目录，
没加进来的文件我读不到。

要说清这一版的边界：这是关键词命中，不是向量检索。同一件事换种说法可能搜不到，
别把没搜到说成「资料里没有」。

## 触发条件

- 知识库里找
- 在我资料里搜
- 查一下我之前的文档
- 本地资料检索
- 帮我找找这份资料

## 输入

- query：要搜的关键词

## 步骤

1. 按关键词找片段 | tool=knowledge_search

## 允许工具

- knowledge_search
- knowledge_status

## 输出格式

按命中片段列出：文件名（位置），下面跟一段摘录和完整路径。
一段都没命中就直说没找到，并提醒这是关键词命中，换个说法再试。

## 验收标准

- 结果来自 knowledge_search 的真实返回，不自己编资料
- 每条都带文件名和位置，能回原文
- 知识库空着时如实说没加目录，不假装搜过

## 失败处理

- 没给关键词：问清要搜什么，不瞎猜
- 知识库还没建：说明要先在「文件与知识」里加目录并扫描
- 搜不到：说清是关键词没命中，不伪造来源
