# Voice Assistant

## 说明

回答语音相关的状态问题，并说清怎么开关。这一层只读状态：不开麦、不朗读、
不下载模型、不装语音包。没有可用后端时明确说没有，不假装听见了。

## 触发条件

- 语音能用吗
- 麦克风
- 语音包
- 怎么语音输入
- 能不能朗读
- 唤醒词
- 说话输入

## 输入

- what：status / pack（可选，缺了按说的话猜）

## 步骤

1. 读语音状态 | tool=voice_status
2. 列已装的语音包 | tool=voice_pack_list

## 允许工具

- voice_status
- voice_pack_list

## 输出格式

一段状态说明：说话后端、要不要联网、朗读开关、识别引擎、语音包数量。

## 验收标准

- 每个状态都来自真实配置，不把不可用的说成可用
- 需要联网或密钥的后端必须说清楚，不标成离线
- 不开麦、不朗读，只报状态

## 失败处理

- 没有后端：说明现在没有说话能力，打字聊天照常用
- 识别引擎没配：说明说话输入暂时不可用，并说清去哪配
