# Local Backup

## 说明

用户的记忆库要能备份，也要能恢复。这个技能管三件事：列出已有备份、
建一份新备份、按用户要求恢复。备份不动现有数据；恢复会覆盖当前记忆库，
所以先校验备份文件、再给当前库留一份副本，而且必须用户确认才执行。
技能本身不给自己加权限，恢复仍要过权限中心那一关。

## 触发条件

- 备份
- 备份记忆
- 有哪些备份
- 备份列表
- 恢复备份
- 还原数据

## 输入

- action：list 看备份、create 建备份、restore 恢复，不给就按 list
- path：恢复时用哪份备份文件

## 步骤

1. 看已有备份 | tool=backup_list
2. 建一份新备份 | tool=backup_create
3. 按确认后的要求恢复 | tool=restore_backup

## 允许工具

- backup_list
- backup_create
- restore_backup

## 输出格式

列表给文件名和大小；建备份给新文件的路径；恢复说明覆盖了什么、原来的库存在哪。

## 验收标准

- 恢复前一定先校验备份文件，不合格直接拒绝
- 没有用户确认就不覆盖任何数据
- 覆盖前先给当前库留一份副本，并把这个路径说出来

## 失败处理

- 备份文件损坏：说清哪里不合格，不强行恢复
- 恢复没被授权：说明这一步要用户单独确认，不绕开权限中心
- 还没有数据库：说明现在没有可备份的内容
