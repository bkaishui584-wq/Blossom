# Blossom 7.0.1 发行说明

## 安装包

- 推荐安装包：`Blossom-7.0.1-win64-setup.exe`
- 绿色版：`Blossom-7.0.1-win64.zip`
- 主程序与安装包文件版本：`7.0.1.0`
- 产品名：`Blossom`

## 本版主要改动

1. 日历新增周视图和日视图，支持前后区间导航；周视图按周一开头，日视图按小时展开当天日程。
2. 日历支持 ICS 导入导出，包含标题、备注、起止时间、优先级、重复规则、提醒和完成状态。
3. ICS 导入先预检，确认后才写库；重复日程按标题和起止时间跳过。
4. ICS 支持 UTC 与 `TZID` 时区转换，未知时区会跳过并显示原因。
5. 新增 `tests/test_p120.py`，覆盖 ICS 转义、折行、预检、去重、时区和三种视图。

## 数据位置

用户数据保存在 `%LOCALAPPDATA%\DeskPet`。安装、升级和卸载默认不会删除用户数据。
