# Blossom 分发说明

这一页写给安装、卸载和排障的人。程序架构见 `README.md`，验收依据见
`docs/acceptance.md`，第三方组件清单见 `THIRD-PARTY-NOTICES.md`。

## 一、当前发行产物

7.0.1 版本包含：

| 文件 | 用途 |
| --- | --- |
| `Blossom-7.0.1-win64-setup.exe` | 推荐的单文件安装包 |
| `Blossom-7.0.1-win64.zip` | 绿色版，可安装也可直接运行 |
| `docs-1.0.0.zip` | 可选文档解析能力包 |
| `voice-1.1.0.zip` | 可选离线语音与音频采集能力包 |
| `*.sha256` | 对应文件的 SHA256 校验值 |
| `Blossom-7.0.1-本版改动说明.txt` | 版本、哈希、验证结果和已知限制 |

安装包和绿色版都面向 64 位 Windows 10/11，不需要管理员权限，也不需要安装
Python、Node.js 或开发工具。

当前安装包没有正式代码签名，Windows 可能显示“来源未知”。校验值只能证明文件没有被改动，
不能替代正式代码签名。

## 二、安装

### 单文件安装包

1. 双击 `Blossom-7.0.1-win64-setup.exe`。
2. 安装器会解压到临时目录，再把程序安装到
   `%LOCALAPPDATA%\Programs\Blossom`。
3. 安装完成后，桌面会出现 `Blossom` 快捷方式。
4. 双击快捷方式启动。第一次启动会显示引导页，说明本机能力、联网能力和数据位置。

### 绿色版

1. 把 ZIP 解压到任意目录，保留完整文件夹，不要只复制 `Blossom.exe`。
2. 想安装到默认位置，双击 `install.cmd`；也可以直接双击解压目录里的
   `Blossom.exe` 免安装运行。
3. 安装模式同样会创建桌面快捷方式。

如果桌面快捷方式没有出现，第一次启动的引导页里有“创建桌面快捷方式”按钮。

## 三、没有模型和网络时

没有模型、没有网络、没有配置任何密钥，程序仍然可以启动。以下能力继续可用：

- 时间、日期、时区、计时器、番茄钟和待办；
- 本地文件搜索、文本处理和项目检查；
- 记忆、人格编辑、权限中心和任务记录；
- 本地诊断、备份、恢复和日志导出。

天气、新闻、网页搜索和普通对话生成需要联网或模型。未配置时界面会明确显示原因，
不会把预设回复伪装成模型推理，也不会自动选择收费模型。

实时字幕也不依赖云端才能启动。没有语音运行库、没有模型目录或模型文件不完整时，
设置页会分别写出缺哪一样，点「开始」不会创建假的识别结果，主聊天和 Live2D 不受影响。

## 四、数据放在哪

程序目录和用户数据目录是分开的。产品名已经改为 Blossom，但用户数据目录继续使用
`%LOCALAPPDATA%\DeskPet`，这样做是为了升级时不丢旧数据和旧配置。

```text
%LOCALAPPDATA%\DeskPet\
├── .env                  用户自己的配置
├── data\
│   ├── deskpet.sqlite3   会话、记忆、任务、偏好、审计
│   ├── skills\           用户技能
│   ├── voices\           语音包
│   ├── devices\          设备清单
│   ├── persona_cards\    导入的人格卡
│   ├── exports\          记忆导出
│   └── secrets\          DPAPI 加密的 API Key
├── live2d\               角色模型
├── packs\                可选能力包
└── logs\deskpet.log      运行日志
```

第一次启动会把随包自带的 `live2D0` 放进 `live2d` 目录。用户自己放入的模型不会被覆盖；
程序不会修改模型文件、动作或物理参数。

重新打包、覆盖程序目录或换一台机器复制程序，都不会动用户数据。反过来，删除这个目录
就等于删除记忆、会话、人格和配置。

所有路径都由程序自身位置和系统目录 API 计算，不依赖当前工作目录。

## 五、备份与恢复

最简单的完整备份：退出 Blossom，把整个 `%LOCALAPPDATA%\DeskPet` 文件夹复制一份。

程序里也有备份入口：

- 记忆窗口的“导出”把记忆写成 JSON；
- “备份整库”复制完整的 SQLite 数据库；
- “恢复整库”覆盖前会先保存当前库的副本，备份文件不存在、不是 SQLite 或结构不符时会拒绝；
- 角色包的备份和恢复只处理清单类小文件，不包含模型和密钥。

恢复完成后重启程序，避免旧连接继续占用数据库。

## 六、出问题时

| 现象 | 处理 |
| --- | --- |
| 双击没反应 | 查看 `%LOCALAPPDATA%\DeskPet\logs\deskpet.log` 最后几行 |
| Windows 提示来源未知 | 当前安装包未正式签名；先用 `.sha256` 校验文件，再决定是否安装 |
| 提示数据无法读取 | 检查磁盘空间和 `%LOCALAPPDATA%\DeskPet` 的写入权限 |
| 角色不显示 | 检查 WebView2 运行时和 `live2d` 目录；角色不可用时仍保留透明拖动区域，聊天不受影响 |
| 模型报错 | 打开“设置 → 模型”，查看连接测试和错误分类 |
| 文档读不了 | 安装 `docs-1.0.0.zip` 文档解析能力包 |
| 语音按钮不可用 | 安装 `voice-1.1.0.zip`，再按界面提示准备语音模型 |
| 设备中心显示未连接 | 没接 ESP32 或没配置串口，不影响其它功能 |
| 桌面快捷方式丢失 | 从引导页点击“创建桌面快捷方式”，或运行程序目录里的 `install.cmd` |

需要给别人排查时，用“设置 → 开发者 → 导出诊断包”。诊断包只包含脱敏报告和日志副本。

## 七、升级与卸载

升级：用新版本安装包再安装一次。安装脚本只覆盖程序目录，用户数据、配置、人格、
记忆和角色模型都保留。数据库按版本增量迁移，迁移前会保留副本。

卸载：

1. 先退出 Blossom；
2. 运行程序目录里的 `uninstall.cmd`；
3. 默认只删除程序目录和桌面快捷方式，保留 `%LOCALAPPDATA%\DeskPet`；
4. 想连数据一起删除，运行 `uninstall.cmd --purge`，脚本会要求输入大写 `YES` 二次确认。

## 八、隐私边界

- 不采集分析数据，不上传聊天内容，不埋点。
- API Key 使用 Windows 当前用户的 DPAPI 加密保存，普通配置只保存引用。
- 日志写入前会脱敏，诊断包导出时再脱敏一次。
- 模型不能直接操作系统，所有动作都经过工具注册表和权限中心。
- 语音、截图、屏幕语义和持续工作记录默认关闭，开启后界面显示真实状态。
- 工作记录只保存应用名、窗口标题、类别、项目和时长；聊天类应用不保存标题。

## 九、第三方组件与能力包

基础包已经包含运行所需的 Python 运行时、Tk 界面、`pywebview`、`pywinauto`、
`openai`、`pyserial`、`tkinterdnd2`、Pillow 和 pywin32。完整版本与许可证
见 `THIRD-PARTY-NOTICES.md`。

| 能力包 | 主要组件 | 不装时 |
| --- | --- | --- |
| `docs-1.0.0.zip` | MarkItDown、pdfminer、openpyxl、python-pptx 等 | 普通文本和 Markdown 仍可读，复杂文档格式不可用 |
| `voice-1.1.0.zip` | sherpa-onnx、soundcard 及运行库 | 离线语音识别和实时音源采集不可用，界面会说明原因 |

以下组件只做检测，不随基础包分发，也不自动下载：Ollama、llama.cpp、Docling、
ripgrep、OCR 引擎和各类语音模型。用户自行安装时，需要自行确认模型和组件的许可证。

`voice-1.1.0.zip` 只装运行库，不带语音模型权重。实时字幕要另外准备流式模型目录，
里面至少要有 `tokens.txt`、encoder 和 decoder 的 `.onnx` 文件；transducer 模型还要
joiner。目录在「设置 → 语音 → 实时字幕」里选择，也可以写到 `DESKPET_STT_MODEL`。
设置页会区分「运行库没装」「模型目录不存在」「文件不完整」「可以启动」，不会自动下载，
也不会创建目录。SenseVoice、Whisper 这类离线模型不能当作实时字幕的流式模型使用。
「测试音源」只做一次短时读取并立即停止；麦克风和系统音频仍分别受权限开关控制。

程序自带一个本项目自己的 Live2D 角色 `live2D0`。其他角色的模型、贴图、动作、
语音包和字体由用户自行提供并确认授权。

## 十、发行验证

先跑打包自检：

```powershell
.\verify_release.ps1
```

它检查每个 zip 和 exe 的 `.sha256`、压缩包能否完整读取、基础包是否混入 `.env`、语音运行库、
日志或用户数据库，以及语音包是否误带模型权重。只读发行目录，不启动程序。

拿到安装包后，先核对 SHA256：

```powershell
Get-FileHash .\Blossom-7.0.1-win64-setup.exe -Algorithm SHA256
```

结果应与旁边的 `.sha256` 文件一致。ZIP 和 EXE 的当前值也写在
`docs/release-notes-7.0.1.md`。

用独立临时数据目录做启动自检：

```powershell
$env:LOCALAPPDATA = "$env:TEMP\BlossomCheck"
.\Blossom.exe --check
```

自检会报告数据库、迁移、记忆全文索引、知识库、界面语义、模型配置和 Live2D 环境。

7.0.1 的实际结果：全量回归 3550 项通过，9 项按平台或可选依赖跳过，0 项失败；
打包程序自检退出码 0。基础包不含 `soundcard`，音频采集运行库只随 `voice-1.1.0.zip` 提供。

## 十一、还没做

- 正式代码签名：入口已接通，但本机没有正式证书。
- 外部干净 Windows 虚拟机的双击安装、首次向导和卸载全流程验证。
- 自动更新和正式更新通道。
- 社区技能市场、技能签名校验和第三方技能分发。
- OCR 引擎、本地模型自动下载、Wi-Fi 加密与设备认证。
- ESP32 真机验证，目前只有协议、模拟器和界面闭环。
- 云同步和多设备同步。

这些能力不会在界面或说明里标成已完成。
