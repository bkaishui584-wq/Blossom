# Blossom 安装与使用

给拿到安装包的普通用户看的一页。不需要装 Python、Node.js 或任何开发工具。

## 一、怎么装

两种形式，任选一种，都不需要管理员权限。

**单文件安装包**：双击 `Blossom-7.0.1-win64-setup.exe`，它会自己解压并安装，
结束时桌面会出现 Blossom 图标。

**绿色版**：把 `Blossom-7.0.1-win64.zip` 解压到任意目录（注意是整个文件夹，
不要只拷 `Blossom.exe`），双击里面的 `install.cmd`。
也可以不装，直接双击解压目录里的 `Blossom.exe` 使用。

两者都会把程序放到 `%LOCALAPPDATA%\Programs\Blossom`（也就是
`C:\Users\<你的用户名>\AppData\Local\Programs\Blossom`），并建一个桌面快捷方式。

桌面上万一没出现图标：第一次打开的引导页里有一个「创建桌面快捷方式」按钮，点一下就会补上。
不想装也可以，直接双击解压目录里的 `Blossom.exe` 就能用。

## 二、第一次启动

双击图标后会看到桌宠和一次性的引导页。引导页会说明：

- 哪些能力**本机就能用**：报时间、待办、提醒、计时器、本地文件搜索、文本整理、自检；
- 哪些**需要配置密钥**：聊天、写作、任务规划（要有模型服务，第一次在「设置 → 模型」里填）；
- 哪些**需要额外下载**：文档解析、离线语音（见下面「能力包」）；
- 哪些**需要硬件**：ESP32 设备（不接也能用，界面会显示离线）。

**没有密钥也能用。** 不配置模型时，程序照常启动，本机能力照常可用，
聊天会如实告诉你「当前没有连接聊天模型」。

## 二点五、配置模型（第一次聊天前）

设置 → 模型 → 模型与 API 管理：

1. 选服务商：OpenAI / DeepSeek / 通义千问 / 自定义兼容接口。地址和模型 ID 会自动填默认值，可以改。
2. 贴自己的 API Key。输入框默认掩码，不会显示明文。
3. 勾选用途：日常聊天、复杂任务（可以都勾）。
4. 点「保存并应用」。想确认真能连上，再点「测试连接」——这会真实发送一次最小请求，可能产生极少量费用。

Key 用 Windows 当前用户的 DPAPI 加密保存在 `%LOCALAPPDATA%\DeskPet\data\secrets\`，
普通配置文件里只有一个引用。换 Windows 用户或换电脑都解不开，需要重填。
聊天顶栏的模型菜单只切换当前会话；新会话默认用「设为聊天默认」的那一套。

## 二点六、换外观（可选）

设置 → 个性化：

- **日夜开关**：胶囊上的圆形开关点一下就在白天/夜晚之间切，滑动过渡。只改界面配色，不碰桌宠模型和动作。
- **渐变主题**：Aurora / Ocean / Sakura / Emerald / Sunset / Lavender / 自定义，共七套。
- **背景图片**：从本机选一张图（PNG / JPG / WebP / BMP），可以缩放；「恢复渐变」换回主题背景。
  程序只记图片路径，不复制、不改你的原图；把原图移走或删掉后，界面会提示并自动用回渐变。
- **背景动效**：关 / 低 / 标准；最小化时自动停，不占后台性能。

文字颜色随主题单独校验过对比度，浅色主题和深色主题下正文都保持清晰。

## 三、你的数据在哪

程序和数据是分开的，重新安装或升级不会碰你的数据。

| 内容 | 位置 |
| --- | --- |
| 配置 | `%LOCALAPPDATA%\DeskPet\.env` |
| 记忆与会话数据库 | `%LOCALAPPDATA%\DeskPet\data\deskpet.sqlite3` |
| 日志 | `%LOCALAPPDATA%\DeskPet\logs\` |
| 角色模型 | `%LOCALAPPDATA%\DeskPet\live2d\`（第一次启动会把随包自带的角色放进来） |
| 角色包、技能、语音包、设备清单 | `%LOCALAPPDATA%\DeskPet\` 下的 `characters\`、`skills\`、`voices\`、`devices\` |
| 角色卡库（导入过的人格卡） | `%LOCALAPPDATA%\DeskPet\data\persona_cards\` |
| 能力包 | `%LOCALAPPDATA%\DeskPet\packs\` |

**备份**：把整个 `%LOCALAPPDATA%\DeskPet` 文件夹复制一份就是完整备份。
程序里也有「备份」入口，装出来的备份文件同样可以留着。

**换电脑**：把 `%LOCALAPPDATA%\DeskPet` 拷到新机器的同一位置即可。

**换角色**：程序自带一个角色，放在 `%LOCALAPPDATA%\DeskPet\live2d\live2D0`。
想换自己的：把模型文件夹放进 `%LOCALAPPDATA%\DeskPet\live2d\`，
再在 `%LOCALAPPDATA%\DeskPet\.env` 里写一行 `DESKPET_LIVE2D_MODEL=<文件夹名>`。
同名文件夹已经存在时程序一个字都不动，你自己的模型不会被顶掉。

**换人格**：人格 → 人格文本 → 「导入角色卡…」，认酒馆的 `.json` 和 `.png` 卡。
导入前会先给你看会写成什么、哪些字段不导入，点了「导入并生效」才生效；
原来的文本留在版本历史里，随时能回滚。导入过的卡会自动留在卡库
（`%LOCALAPPDATA%\DeskPet\data\persona_cards\`），下次在「角色卡库」下拉里选一下就能切回来。
内置了 12 张卡（6 张原创 + 6 位公版人物），第一次启动就已经在卡库里。

## 四、升级

用新版本的安装包再装一次即可。安装脚本只覆盖程序目录，
`%LOCALAPPDATA%\DeskPet` 里的数据、配置和角色一个都不动。

数据库升级是向前兼容的：程序启动时按版本号补齐新表，
迁移前会自己留一份副本，迁移失败会保留旧数据并在日志里说明原因。

## 五、卸载

运行程序目录里的 `uninstall.cmd`，或者从快捷方式所在目录找到它。

- 默认**只删程序**，`%LOCALAPPDATA%\DeskPet` 里的记忆、配置和角色包全部保留；
- 想连数据一起删，运行 `uninstall.cmd --purge`，会二次确认后再删。

## 六、能力包（可选，按需下载）

基础包不包含文档解析和离线语音：它们合计一百多 MB，多数人用不到。

| 能力包 | 装上之后 | 不装时 |
| --- | --- | --- |
| 文档解析 | 能读 docx / xlsx / pptx / pdf / html 这类文件 | 这些格式读不了，纯文本和 Markdown 照常 |
| 离线语音 | 装上 sherpa-onnx 与 soundcard 运行库，实时字幕、离线识别和音源采集可以加载本机模型 | 语音按钮不可用，界面写明原因 |

装法：把能力包 zip 放到电脑上，在程序里「本地能力与权限」页选择安装；
也可以手动解压到 `%LOCALAPPDATA%\DeskPet\packs\<名字>\`，下次启动自动生效。
每个包自带完整依赖，不需要另外装任何东西。

离线语音包不包含模型权重，程序也不会自动下载模型。要用实时字幕时，另外准备一个
流式模型目录，里面放 `tokens.txt`、encoder 和 decoder 的 `.onnx` 文件；如果是
transducer 模型，再放一个 joiner `.onnx`。在「设置 → 语音 → 实时字幕」里选中这个
目录，点「检查状态」，状态会如实显示运行库、模型文件和目录是否齐全。直接用命令行
启动时也可以写 `DESKPET_STT_MODEL=<模型目录>`。SenseVoice、Whisper 这类离线模型
不能拿来做实时字幕。

音源列表旁边有「测试音源」。它只在点击后读很短一段，显示实际音量，不会常驻录音。
第一次使用系统音频或麦克风前，要先在权限页打开对应开关。

## 七、出问题了怎么办

先看日志：`%LOCALAPPDATA%\DeskPet\logs\deskpet.log`。

| 现象 | 可能原因与处理 |
| --- | --- |
| 双击没反应 | 看日志最后几行；程序启动失败会弹一句人话提示 |
| 提示数据无法读取 | 磁盘满或目录权限被改；确认 `%LOCALAPPDATA%\DeskPet` 可写 |
| 角色不显示，桌面上只有透明拖动区域 | 打开「设置 → 角色」，那一页会写明原因：最常见的是缺 Edge WebView2 运行时（Win10/11 一般自带），按提示装一次即可 |
| 提示没有连接模型 | 打开「设置 → 模型」填 Key 和模型，点「保存并应用」；本机能力不受影响 |
| 设备中心一直显示未连接 | 没接 ESP32，或者没在设备清单里写串口；不影响其它功能 |
| 文档读不了 | 没装「文档解析」能力包 |

## 八、已知限制

- Live2D 画面依赖随 Windows 一起分发的 Edge WebView2；精简版系统可能需要单独装一次。
- 串口相关功能需要 pyserial（已随包），但连真机需要你自己接线并在设备清单里配置端口。
- 离线语音需要单独的能力包，模型权重另放；没有模型时只能用文字。
- 程序自带一个 Live2D 角色（可以随时按上面的办法换掉）；语音模型和 OCR 模型不分发，需要自己准备。
