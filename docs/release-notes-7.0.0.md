## 本版主要改动

1. 人格情境：陪伴、工作、休息、勿扰四种本地情境，可影响主动搭话节奏。
2. 工作记录：默认关闭，明确授权后记录前台应用与时长；支持暂停、项目归类、日报周报、导出和删除。
3. Skill 与模型：保留本地优先路由、Skill 权限边界和聊天/任务双模型。
4. 模型观测：记录调用状态、耗时、Token 和脱敏错误，不保存提示词与回复正文。
5. 本地模型：新增 Ollama 预设，不需要云 API Key，模型仍需用户自行安装和拉取。
6. 实时字幕：支持系统音频或麦克风采集、流式识别、翻译、独立浮窗、字幕历史和三种导出格式。
7. 打包收尾：基础包不再携带 `soundcard`，音频采集运行库只放在 `voice-1.1.0.zip`；发行目录只保留最高版本能力包。
8. 诊断脱敏：日志和诊断包会统一隐藏 `password`、`passwd`、`secret`、`api_key`、`token`、`Authorization` 等字段的值。

## 数据位置

用户数据保存在 `%LOCALAPPDATA%\DeskPet`。安装、升级和卸载默认不会删除用户数据。

## 已知限制

- 当前安装包未做正式代码签名，Windows 可能提示来源未知。签名流程已经接通，但本机没有正式代码签名证书。
- 尚未在外部干净 Windows 虚拟机完成双击安装、首次向导和卸载全流程验证。
- 文档解析和离线语音是独立能力包，不包含在基础安装包内。
- 离线语音和实时字幕只完成运行库、状态检查和模拟音频测试；真实麦克风与系统音频的端到端录音未在本机执行。
